# GitHub Pages and the `go/` pages

`go/` holds one page per channel we post on: `x` (X), `bsky` (Bluesky), `masto` (Mastodon), `gh` (GitHub).

- `go/<channel>.md` is a landing page, read on github.com. Posts link here, with `#<actor-name>` pointing at
  the Actor's section. GitHub's repository traffic API counts these page views per path, which is how we
  see which channel sends readers (the count of a page, never who the reader was).
- `go/<channel>.html` is a redirector for GitHub Pages: `https://atarivo.github.io/apify-actor-examples/go/x.html?a=<actor-name>`
  sends the reader to `https://apify.com/atarivo/<actor-name>` when the name is one of our Actors, and to
  https://apify.com/atarivo otherwise. Without JavaScript it refreshes to the org page and shows the links.
  GitHub publishes no traffic numbers for Pages, so posts do not use it by default.

Pages serves this repository from the `main` branch root. `.nojekyll` turns off Jekyll, so files are
served as they are. These pages are generated by the factory (`python -m factory.promo redirector`);
edit the generator, not the files.
